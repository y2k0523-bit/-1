# 사이언스 러너 — 실시간 멀티플레이

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

## 여러 학생 접속

같은 Wi-Fi의 다른 기기는 교사 컴퓨터의 내부 IP와 포트 3000으로 접속할 수 있습니다. 예: `http://192.168.0.10:3000` (실제 주소는 컴퓨터마다 다릅니다). 컴퓨터 방화벽에서 3000 포트 접속이 허용되어야 합니다.

외부 네트워크에서도 접속하려면 WebSocket을 지원하는 Node.js 호스팅(Render, Railway, Fly.io 등)에 프로젝트를 배포하고 HTTPS 주소를 공유합니다. **정적 HTML 호스팅만으로는 실행할 수 없습니다.** 무료 호스팅의 절전·접속 제한에 유의하세요.

1. 교사: 교사 모드 선택 → 방 코드 없이 입장 → 6자리 코드 확인
2. 학생: 학생 모드 선택 → 이름과 6자리 코드 입력 → 입장
3. 30초 후 자동 시작 또는 교사 수동 시작

## 현재 버전의 제한

- WebSocket 기반 실시간 위치 및 경기 상태 동기화, 교사 제어, 문제 타이밍 공유를 구현한 **시험용 멀티플레이 버전**입니다.
- 학생별 이동 및 정답 판정은 클라이언트에서 계산하므로 부정행위 방지나 서버 권위 판정은 아직 없습니다.
- 방 데이터는 서버 메모리에만 있으며 서버를 재시작하면 사라집니다.
- 교사가 연결 해제되면 재접속으로 기존 교사 권한을 복구할 수 없습니다.
- 실제 30~40명 동시 플레이 부하 테스트는 아직 하지 않았습니다.
- 인터넷에 공개할 경우 교사 인증, 방 접근 통제, 속도/점수 검증, 메시지 제한 등의 보안 개선이 필요합니다.

## 배포 설정

- Render Web Service / Node / main
- Build: `npm ci`
- Start: `npm start`
- Health endpoint: `/healthz`
- 서버는 `0.0.0.0` 및 `PORT` 환경 변수에 바인딩합니다.
- 정적 HTML과 WebSocket 서버를 같은 서비스에서 실행합니다.

## 회귀 검증

```bash
npm test
```

교사·학생 입장, 이동 공유, 학생의 교사 명령 차단, 일시정지, 재시작을 실제 WebSocket으로 검증합니다. 공개 서비스에서의 검증은 별도로 진행해야 합니다.
